# Proposed font specimens

These files support the offline review gallery. They are not registered as application assets.

- Barlow Condensed ExtraBold 800: headings/actions.
- Barlow Condensed Black 900: score and celebration display.
- Barlow Regular 400: body and supporting text.
- Barlow SemiBold 600: names and utility labels.

Downloaded 2026-09-07 from the official [Google Fonts Barlow Condensed](https://github.com/google/fonts/tree/5e35378e6bda803962ee6fd257e444a7d459660d/ofl/barlowcondensed) and [Barlow](https://github.com/google/fonts/tree/5e35378e6bda803962ee6fd257e444a7d459660d/ofl/barlow) directories at revision 5e35378e6bda803962ee6fd257e444a7d459660d. Their metadata identifies the license as OFL. License texts are preserved beside the fonts.

The gallery renders the real files. Lettering in the ImageGen mockups remains approximate and is not a different approved typeface. Validate native Flutter font metrics and numeral features during implementation.
